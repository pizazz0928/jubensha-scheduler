# 门店使用说明

## 第一次使用

1. 使用店主账号登录。
2. 进入 DM 状态，停用演示 DM，再添加真实 DM。
3. 进入剧本管理，停用演示剧本，再添加门店剧本。
4. 为每个剧本维护可主持 DM 和熟练度。
5. 进入房间管理，维护真实房间、容量、支持类型和房态。
6. 回到今日调度，创建当天场次。

停用资料会保留历史场次引用，适合替代删除。

## 创建临时场次

1. 点击右下角“临时开本”。
2. 选择剧本、开始时间、玩家人数和房间。
3. 玩家昵称可以每行填写一个，也可以使用逗号分隔。
4. 查看推荐主 DM 和风险信息。
5. 保存场次。

房间容量、支持类型、清理状态或时间冲突不符合要求时，系统会阻止保存。

## 安排和更换 DM

1. 在场次卡片点击“安排 DM”或“换 DM”。
2. 查看候选人的熟练度、状态和推荐理由。
3. 选择 DM 并填写调整原因。
4. 确认后检查场次卡片和 DM 状态。

系统会检查主持资格、在店状态、时间冲突和玩家身份冲突。每次交接都会增加交接次数并写入日志。

## DM 玩家补位

1. 在缺玩家场次点击“添加补位”。
2. 选择允许补位且当前空闲的 DM。
3. 真实玩家到店后打开场次详情。
4. 点击对应补位 DM 的退出操作。
5. 系统保持玩家总数并把 DM 恢复为空闲。

剧情进入无法换人的阶段时，店主应先与主持人确认，再执行退出。

## 编辑玩家名单

打开场次详情，在玩家名单中每行填写一个昵称。人数减少时，超出人数的末尾昵称会被移除。DM 补位单独显示，不计入真实玩家昵称的可填写数量。

## 开始、结束和取消

- 开始前必须有主 DM，且人数达到剧本最低要求。
- 开始后，主 DM 进入主持中，补位 DM 进入玩家补位中，房间进入使用中。
- 结束后，相关 DM 自动恢复空闲，房间进入清理中。
- 清理完成后，在房间管理中将房间标记为空闲。
- 取消场次会释放相关 DM 和房间。

## 并发提示

手机和电脑可以同时使用。两个页面同时修改同一版本数据时，先保存的一方成功，另一方会收到刷新提示。刷新后重新操作即可。

## 每日收店检查

1. 确认所有已完成场次都已结束。
2. 确认没有 DM 遗留在主持中或玩家补位中。
3. 更新需要清理的房间状态。
4. 在记录统计中检查当日调整记录并按需导出 CSV。
5. 重要资料变更后按备份说明导出备份。

## 下载和恢复备份

管理员进入“记录统计”后可以下载完整备份。恢复时选择备份文件，并准确输入页面要求的确认文字。恢复会覆盖当前全部资料和场次，操作前应先下载当前数据备份。

## 故障处理

- 页面无法打开时，先访问 `/healthz`。
- `/healthz` 返回 503 时，联系云服务维护人员检查 MySQL。
- 登录失败时核对账号密码，连续多次失败后等待 15 分钟。
- 数据与另一设备不同步时刷新页面，系统也会定时拉取最新数据。
- 操作被冲突检查拒绝时，先调整 DM、房间或时间安排。
